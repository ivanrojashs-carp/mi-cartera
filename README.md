# Mi Cartera

Seguimiento personal de inversiones (acciones, CEDEARs, bonos, cripto) en pesos y dólar CCL, con rendimiento mensual contra inflación y S&P 500, mapa de calor y desarbitrajes de CEDEARs.

- Sin cuentas ni servidor: los datos quedan en el navegador de cada dispositivo. Pasalos entre equipos con **Datos → Exportar / Importar respaldo**.
- iPhone: abrir en Safari → Compartir → *Agregar a pantalla de inicio*.
- Windows 11: abrir en Edge → ⋯ → *Aplicaciones → Instalar este sitio como aplicación*.

Fuentes de precios: data912.com, dolarapi.com, argentinadatos.com, Binance.
